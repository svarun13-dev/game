## 🎯 Quick Reference

### Game Concept
2D Action-RPG set in mythological Atlantis before the Great Flood. JRPG aesthetics meet Greek mythology with action-based combat and moral choices.

### Key Features
- **6 Playable Classes:** Warrior, Mage, Archer, Priest, Rogue, Animalist
- **Dual Magic System:** Traditional Mana + Atlantean Solar Energy
- **Open World:** Witcher/WoW-style exploration
- **Moral Choices:** Shape the story and ending
- **Action Combat:** Real-time, skill-based

### Demo Scope
- 1-2 hours gameplay
- 1 fully playable class (expandable to 6)
- Central Atlantis city + outdoor zone + dungeon
- Basic story introduction
- Core combat and progression systems

## 📋 Open Questions (To Decide)

From GAME_DESIGN_DOCUMENT.md:

1. **Hero's name and specific background?**
   - Suggestion: Let player choose name, background tied to class

2. **Which class to prototype first?**
   - Recommendation: Mage (shows off effects) or Warrior (simplest)

3. **Flood timeline transparency:**
   - Does player know about flood from start or discover it?
   - Recommendation: Prophetic dream opening, then investigate

4. **Companion system:**
   - Solo only, or plan for party members?
   - Recommendation: Solo for demo, design for future companions

5. **Save system scope:**
   - Autosave only, manual save, or both?
   - Recommendation: Both (autosave + 3 manual slots)
